# Family AI Assistant — NetMind

Локальная система домашнего ИИ-помощника на базе собственного оборудования.

## Персонажи
- **Диций** — наставник, стратег, дворецкий
- **Киёхиме** — домоправительница, быт и организация
- **Пан** — шеф-повар, консультатнт по питанию
- **Шикагэ** — охрана периметра

## Оборудование
- ASUS G75VX — главный вычислительный узел (Диций)
- Toshiba C850 — узел Киёхиме и Пан
- TerraMaster F4-212 — хранилище данных
- HP Compaq 6820s — Home Assistant
- MicroXperts — сетевой страж

## Стек
Ollama • Open WebUI • Docker • PostgreSQL • n8n • Qdrant • Nextcloud
